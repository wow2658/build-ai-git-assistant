# Git 커밋 자동화 도구: AI 모델 배제 사유서

본 문서는 **Git Commit Assistant (CLI 도구)** 개발을 위한 최적의 AI 모델 선정 과정에서, 후보군에서 제외(필터링)된 모델 및 도구들의 카테고리별 명확한 배제 사유를 정리한 자료입니다.

## 1. Live API (실시간 스트리밍 모델)
- 포함 모델: Gemini 2.5 Flash Native Audio Dialog, Gemini 3.5 Live Translate 등
- 배제 사유: 본 프로젝트는 텍스트(git diff)를 한 번 전송하고 커밋 메시지를 한 번 응답받는 단순 REST API 구조입니다. 실시간 음성 양방향 통신(WebSocket) 기능은 불필요한 오버스펙입니다.

## 2. 구분이 '도구(Tools)'인 항목 전체
💡 참고: 대시보드 표에서 구분이 '도구'로 되어 있는 항목들은 AI 모델 자체가 아니라, AI에게 쥐여주는 '추가 기능(무기)'의 사용 한도를 뜻합니다. 본 프로젝트는 순수 텍스트만 분석하므로 어떠한 도구도 필요하지 않아 전체를 배제하였습니다.
- 검색 그라운딩 도구: 외부 인터넷 검색 기능입니다. 로컬 코드 변경 사항(git diff)만 분석하면 되므로 불필요합니다.
- 맵 그라운딩 도구: 구글 지도(Google Maps) 검색 기능입니다. 코드 요약과 지리적 위치는 전혀 무관합니다.

## 3. 멀티모달 생성 모델 (이미지/영상/음성)
- 이미지/영상 생성 (Imagen, Veo 등): 커밋 메시지를 예쁜 그림이나 영상으로 받을 이유가 없습니다. 우리는 순수 텍스트 문자열이 필요합니다.
- TTS (Text-To-Speech): 생성된 커밋 메시지를 로봇 목소리(MP3 등) 오디오 파일로 다운로드 받아 터미널에 칠 수는 없습니다.

## 4. 임베딩 모델 (Embedding)
- 포함 모델: Gemini Embedding 1, 2 등
- 배제 사유: 텍스트를 컴퓨터용 숫자(벡터)로만 변환해줄 뿐, 사람이 읽을 수 있는 텍스트(요약본)를 생성하지 못합니다.

## 5. 로보틱스 모델 (Robotics)
- 포함 모델: Gemini Robotics ER 시리즈
- 배제 사유: 물리적인 로봇(로봇 팔 등)을 제어하기 위한 두뇌 모델입니다. 소프트웨어 코드 요약과는 목적이 완전히 다릅니다.

## 6. 에이전트 모델 (Agents)
- 포함 모델: Antigravity, Deep Research Pro 등
- 배제 사유: 단발성 텍스트 요약이라는 가벼운 작업에 쓰기에는 뼈대가 너무 무겁고 복잡하며, 하루 할당량(RPD)도 매우 낮아 부적합합니다.

## 7. 할당량(RPD) 부족 텍스트 모델
- 포함 모델: Gemini 2.5 Flash 등 (하루 20번 제한)
- 배제 사유: 개발자는 하루에도 수십 번씩 커밋을 합니다. 하루 20번 제한으로는 실무 테스트조차 벅찹니다. (Gemma 4 26B는 하루 14,400번 가능)

---
🚨 **최종 결론**
위와 같은 소거법을 통해 불필요한 모델들을 모두 배제한 결과, 텍스트 요약에 특화되어 빠르고, 하루 14,400회(Google AI Pro 멤버십 기준이어서 저는 병철님의 1500회와 달랐습니다.)의 압도적인 무료 할당량(RPD)을 제공하는 **Gemma 4 26B** 모델을 최종 선정하였습니다.
